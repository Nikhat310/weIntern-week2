# TechNova Website

## Project Overview
TechNova is a responsive, multi-page company website built using HTML, CSS, and JavaScript.

## Pages
- Home
- About
- Services
- Contact

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Flexbox and CSS Grid
- Font Awesome icons

## Features
- Responsive design for desktop, tablet, and mobile
- Consistent styling across all pages
- Mobile navigation menu
- Contact form validation
- Reusable CSS styles

## How to Run
1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open `index.html` using Live Server.
4. Navigate through the other pages using the website menu.

## Note
The contact form currently performs client-side validation only. It does not send messages to a backend or email service.
